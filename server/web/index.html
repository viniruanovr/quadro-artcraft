Guia

Começar

  1. Arraste fotos para o quadro (ou Ctrl+V).
  2. Puxe um fio da bolinha da direita e solte no vazio: nasce um nó Gerar.
  3. Escreva no fio o que gerar e clique em ✦ Gerar.
  4. TL manda o resultado para o playhead do FilmCraft.

Motor de geração

…

Uma vez só: entre em kaggle.com, verifique o telefone da conta (Settings › Phone verification), depois em Settings › API gere um token. Cole aqui o token (começa com KGAT_) e o seu usuário (aparece no endereço do seu perfil: kaggle.com/usuário). Se baixou um arquivo kaggle.json, pode escolher ele em vez disso. Pronto: ao clicar em Gerar, o quadro liga uma GPU grátis no seu Kaggle (a primeira geração do dia leva uns 10 minutos para ligar) e desliga sozinho após 25 minutos sem uso.

Em app.getartcraft.com › Account › Settings › API Keys. Se a seção não aparecer, a ArtCraft precisa liberar a API na sua conta (Discord da ArtCraft).

No ComfyUI, abra um modelo que funcione na sua placa, teste uma vez e use Workflow › Export (API). Escolha aqui o arquivo salvo.
